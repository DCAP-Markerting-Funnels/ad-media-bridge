# Agent instructions — Ad Media Bridge

This is a current-approved-media delivery bridge, not a creative workspace, archive or launch authorization.

- Read README.md and catalog.json first.
- Never upload draft, rejected, superseded or correction-requested artwork. Confirm approval of the exact current file from the human or authorized source; filenames do not grant approval.
- Never commit media binaries or editable source files. Use replaceable assets on the single current delivery release so artwork does not accumulate in Git history.
- Never publish credentials, customer data, private strategy, full review documents or private local paths.
- Add a catalog item only after its real release upload, public URL, type, byte size, dimensions and SHA-256 are verified. No placeholder artwork records.
- Keep only current approved catalog records. Remove withdrawn/correction-requested items and their release assets; no media archive folders or old media releases.
- Store platform-specific returned media IDs privately. Source removal does not delete copies on ad platforms.
- Use supported authenticated plugins/APIs. Do not bypass denials or put tokens in delivery URLs.
- Keep test ads paused. Repository access, artwork approval and upload are not permission to activate ads or spend.
- Report exact files, checksums, URLs, platform results and observed previews. Separate implemented behavior from planned automation.
